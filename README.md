### Olá, sou o Carlos.

Concluí um CTeSP em **Segurança e Proteção de Dados para Sistemas de Informação** e desenvolvo projetos que cruzam segurança, dados e software. Gosto de partir de necessidades concretas, experimentar uma solução e perceber como se comporta fora do editor.

Este perfil reúne trabalhos académicos e projetos pessoais. A documentação distingue o que já está implementado do que ainda estou a desenvolver.
